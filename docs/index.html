Client guides

Clash、V2RayN 与小火箭怎么导入

Clash 节点

使用 Clash YAML 链接。在 Profiles 或配置订阅中粘贴 URL，下载后选择该配置。不同客户端名称略有差异。

V2RayN 节点

使用 Base64 链接。在“订阅分组”中添加 URL，更新订阅后从服务器列表选择节点。

Shadowrocket / 小火箭

使用 Base64 链接。点击右上角加号并选择 Subscribe，粘贴 URL 后更新。iOS 客户端版本不同，菜单文字可能不同。
