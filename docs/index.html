Public subscription directory

免费节点订阅：选对格式，直接导入。

为 Clash、V2RayN、v2rayNG 与 Shadowrocket（小火箭）提供两种清晰的订阅格式；每两小时更新，并公开说明来源、命名和格式校验范围。

For V2RayN & Shadowrocket
Base64 通用订阅URI 格式，适合支持多协议订阅的客户端。
For Clash & Mihomo
Clash YAML 配置YAML 格式，适合 Clash 系配置客户端。

Methodology

公开来源，清楚说明处理过程

01 · SOURCE读取公开 Base64 与 Clash YAML 数据源。
02 · NORMALIZE解析 URI、校验 YAML，并按 IP 地理归属生成国旗和国家缩写。
03 · PUBLISH只发布 Base64 与 Clash YAML 两种可直接导入的格式。
格式校验，不承诺可用性。

公共节点的速度、稳定性和地区可用性会随网络环境变化；请不要用它们处理账号、支付或其他敏感信息。
