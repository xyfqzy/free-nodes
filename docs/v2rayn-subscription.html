V2RayN Base64 guide

V2RayN 节点订阅怎么添加

V2RayN 使用 Base64 通用订阅。该格式包含标准 URI 节点，适合 V2RayN、v2rayNG 和支持 URI 的客户端。

V2RayN 订阅链接

https://nodes.udptoos.com/subscriptions/base64.txt

导入步骤

  1. 复制上方 Base64 URL。
  2. 在 V2RayN 的「订阅分组」中新增订阅。
  3. 更新订阅后，从服务器列表选择节点。
不要混用格式：Clash / Mihomo 使用 Clash YAML 配置，不是本页面的 Base64 链接。

常见问题

订阅里有 VLESS、VMess、Trojan 或 Shadowsocks，正常吗？

正常。Base64 通用订阅可以包含多种 URI 协议；客户端是否支持取决于其版本与内核。

为什么节点连接不上？

公共节点的状态和地区可用性会变化。更新订阅并切换节点后仍不可用时，请检查客户端日志和本地网络规则。
