Clash YAML guide

Clash 节点订阅怎么导入

这是一份面向 Clash Meta、Mihomo、Clash Verge 与 ClashX 用户的 YAML 配置订阅说明。Clash 应使用 YAML 配置，而不是 Base64 URI 订阅。

Clash 订阅链接

https://nodes.udptoos.com/subscriptions/clash.yaml

导入步骤

  1. 打开客户端的 Profiles、配置或订阅管理页面。
  2. 添加上方 YAML URL，并下载或更新配置。
  3. 选择该配置后再选择代理策略或节点。
格式提示：若客户端提示配置格式错误，请确认使用的是 Clash YAML 链接；V2RayN 与 Shadowrocket 应使用 Base64 通用订阅。

常见问题

为什么更新后节点名称带国旗和国家缩写？

名称如 `🇭🇰HK - udptoos.com` 用于识别节点 IP 的公开地理归属。它不代表速度或稳定性承诺。

订阅更新失败怎么办？

先确认网络能访问该地址，再检查客户端是否支持 YAML 配置。公共节点可能随时变化，不适合敏感数据传输。
